A collection of fully **open source** multiplayer games I'm working on for [@modcommunity's](https://moddingcommunity.com) [**gaming platform**](https://moddingcommunity.com/play) with [@godotengine](https://godotengine.org). Check them out [here](https://moddingcommunity.com/play)!

## My Goals
### Focusing On Community Servers
These games along with the gaming platform in general thrive off of **community servers**. With this, one of my **main goals** with these games and the platform in general is to allow any user to spin up a server running one or more of these games using the [Dot Server Deploy](https://github.com/modcommunity/dot-server-deploy) repository.

When running servers for these games, the server (or game) owner may change the game's and addon's configuration settings to make the gameplay unique. Users can then list their server (and game) on our gaming platform where users can easily join through the web browser, desktop app, or mobile (cross-platform).

### Multi-Game Server Support
Another unique feature for this platform is the support for running **multiple games** at once on your server and being able to switch between them seamlessly while players are already connected. When the game (or map) changes, players automatically download all of the content from our global CDN. The CDN syncs files from [**Assets**](https://moddingcommunity.com/assets) on our website under Godot or the game you're making the content for. With that said, it uses repo versioning and tagging similar to [@github](https://github.com) for security, deployment, conflict, and such.

If you've played community and modded servers on games like [Garry's Mod](https://store.steampowered.com/app/4000/Garrys_Mod/) or Counter-Strike, you may have noticed how servers can change maps and then have the current players download and mount the new map plus any other additional content needed.

This is the thought process behind everything and while games **do have separate maps still**, the maps and games loading mechanism is nearly the same under the hood.

## Games
### [G2g Fast](https://moddingcommunity.com/g2gfast) ([My Server](https://moddingcommunity.com/g2gfast/s/g2gfast01/play))
Bunny hop and surf timer game with Source-style movement, zones and leaderboards. This is similar to Counter-Strike Surf Timer and Bunny Hop.

### [Playground](https://moddingcommunity.com/playground) ([My Server](https://moddingcommunity.com/playground/s/pg01/play))
Physics sandbox where you spawn props, NPCs, and weapons and build whatever you like. Garry's Mod was a big inspiration if you haven't noticed :)

### [Arena](https://moddingcommunity.com/arena) ([My Server](https://moddingcommunity.com/arena/s/arena01/play))
Fast first-person deathmatch shooter with different game modes such as GunGame. Pick a loadout, jump into a match and play. Also includes some classic **Surf Deathmatch** maps from older Counter-Strike games!

### [Hungario](https://moddingcommunity.com/hungario) ([My Server](https://moddingcommunity.com/hungario/s/hungario01/play))
2D multiplayer game where you steer a hungry monster, eat to grow and try to outlast everyone else. Inspired off of the classic fun web browser game, [Agario](https://agar.io)!

### [Buses From Hell](https://moddingcommunity.com/buses-from-hell) ([My Server](https://moddingcommunity.com/buses-from-hell/s/bfh01/play))
A minigame where players must survive being run over by one or more crazy bus drivers!

### [Smash Copter](https://moddingcommunity.com/smash-copter) ([My Server](https://moddingcommunity.com/smash-copter/s/smash01/play))
A minigame where players must survive on unstable platforms while props are shot up into the air and fall on top of them.
